## 一、它是什么，不是什么

**它是：**
- 一台把“不确定性”整理成“可看清、可核对的结构”的思维工具；
- 一次在公开数据与明确假设之下，对不确定未来进行的**压力测试**；
- 一种“先推演、后决策、向海图强”的工作方式的具体示范。

**它不是：**
- 不是对未来的精确预测，不预测具体产值、招商成败或台风损失；
- 不是因果神谕，不轻易使用“因为 A 所以 B”；
- 不构成任何投资建议，也不替代官方决策。

风洞不替人做决定，它只负责把“看不见的未来”，提前跑给你看。

## 三、核心观点（Demo 版的几点提示）

1. 惠东是一座**第三产业占 53%、第二产业占 35.5% 的海洋大县**，海岸线 214.3 公里、海域 3200 平方公里。
2. 惠东的命门是**“海”**：214 公里岸线上，旅游、核电、海上风电、LNG、渔业与海龟保护区共用同一片海，彼此既互补也竞争岸线。
3. **稔平半岛**集聚千亿级清洁能源（太平岭核电、港口海上风电、LNG、抽水蓄能）、新材料产业园与两大科学装置，是向海图强的主战场。
4. 滨海旅游年近 1800 万人次，2026 年国庆以 76.4 万人次登顶同程全国热门县域目的地榜首；但客流仍较集中于旺季，全季全时还有空间。
5. **台风是脉冲、不是慢性失血**：今年强台风“红霞”当年净损失约 6.3 亿、占全县 GDP 不到 1%，但对一户旺季民宿、一片渔排可能是一整年的指望；按抗台标准建设的核电、风电几乎无损，多元布局本身就是韧性。
6. 女鞋时尚化、农渔品牌化（赤岸蚝、冬种马铃薯），是把利润与年轻人留在家门口的关键一步。

> 以上均为“结构提示 / 关联 / 同步变化”，不是因果断言，更不是定论。

## 四、数据来源与分级

本项目数据**全部来自公开渠道**，并按可信度分级，报告中可逐项追溯：

- **实测**：统计公报、政府工作报告、计划执行报告、县情概况中直接给出的数字；
- **推估**：台风损失、客流恢复等基于公开停业、复产报道的模型测算；
- **代理**：镇街级热度、打卡代理，非逐镇街实查；
- **假设**：网络边权重、五条路径贡献区间等。

主要公开来源包括：惠东县人民政府门户网站、惠东县统计公报、政府工作报告与计划执行报告、惠州市政府网、南方+/惠州日报、文旅与农业农村部门公开信息等。

**数据时效性说明：** 本项目以 2025 年公开数据为锚（GDP 861.25 亿、规上工业总产值 576 亿等），2026 年国庆、核电投产、台风等为年内公开报道。下一年度统计公报发布后，部分数字可能微调。

我们坚持：**可以讨论参数，但不能杜撰数据**；抓不到的数字宁可留空标“暂缺”，也不用默认值假装抓到了。

## 五、模型边界（请务必阅读）

1. **不是预测器**：只在一组公开数据与明确假设下给出叙事分布与结构提示；
2. **不做因果断言**：单一地区、有限时间序列的汇总数据，不足以支撑严格因果结论；
3. **反事实不可验证，但参数可核对**：“台风更强、核电晚投产会怎样”无法重演，但每个参数都能回到公开资料核对；
4. **不构成投资建议**，亦不替代任何官方决策，结论随假设改变而改变；
5. **互动数据为本机计数**：点赞、投票保存在用户自己的浏览器中，不汇总为全站统计。

## 六、技术细节与可复现性

### 网络：33 节点、46 条主边

网络拓扑为作者根据公开主体与公开关系构建，**非政府统计**。节点涵盖外部区域（深圳、广州、深汕合作区、香港等）、空间载体（平山、大岭、稔山、巽寮、平海、港口、吉隆、黄埠等）、产业主体（核电、海上风电、LNG、新材料、两大科学装置、女鞋、文旅、马铃薯、渔业）与人群（游客、工人、建设者、渔民、深圳周末客）。每条主边标注 A/B/C/D 血统。

中心性提供三把尺子：

- **连接数（Degree）**：一个节点直接连了多少条边——“谁最热闹”；
- **介数中心性（Betweenness，Brandes 算法）**：多少条最短路径必经此节点——“谁是咽喉”；
- **接近中心性（Closeness）**：到其他节点平均距离的倒数——“谁到哪都近”。

> 三把尺子的“第一名”往往不同：**“最大”不等于“最必经”，“热闹”不等于“咽喉”。**

### 蒙特卡洛：mulberry32 可复现伪随机

未来模拟使用 **mulberry32 伪随机数生成器（PRNG）**，五条路径均按正态分布 N(μ,σ²) 生成增量，再加性叠加全局噪声：

- **同种子必同结果**：默认种子 42，相同参数与次数输出完全一致；
- **快速／完整模式**：1000 次（适合手机）／10000 次（更精确分布）；
- **参数全公开**：五条路径 μ/σ 在页面透明面板列出，可自行修改复算。

### 台风：脉冲冲击＋指数恢复

风洞页把台风作为**脉冲**处理，区别于惠城过江通道的日常慢性拥堵：

- **当年净损失** `typhoonLoss(strength, days)`＝旅游停业（扣除可改期回补）＋渔业与海洋牧场设施损失；核电、海上风电按抗台标准建设，损失记 0；
- **客流恢复曲线** `typhoonCurve`：登陆当周为谷底，随后按指数 `exp(-0.75·w)` 逐周回升，约 5–7 周回到趋势；
- 恢复曲线与 GDP 结果由**同一机制**生成，台风参数同时进入两处，避免“两张皮”；模型保守地不假设长期口碑损失。

### 灵敏度：两本账，不混排

| | 参数敏感性 | 受控场景压测 |
|---|---|---|
| 所在页面 | ⑤ 未来页 | ⑥ 风洞页 |
| 方法 | 单条路径 ±20%，其他不变，**同种子**重跑 | 注入台风、核电延迟、女鞋景气变化 |
| 回答 | “哪个参数最敏感？” | “如果这件事发生，会怎样？” |

## 七、为什么做这件事

临海地区的每一个重大决策，最终都落在具体的人身上——一户旺季满房、平日空置的民宿，一片靠海吃饭的渔排，一家正在转型的鞋厂。投进去的是真金白银，台风一来、项目一拖，代价直接压到具体家庭。

这与国家方向高度一致：海洋强国建设、数字中国、生态文明、乡村振兴与粤港澳大湾区建设，都要求把蓝色国土的开发与保护算清楚、规划好，让海洋资源变成老百姓摸得着的收入。

这个小小的 Demo，正是把上述理念落到一个临海县的、具体而微的一次尝试。
