# 惠东产业沙盘 · huidong-simulator

惠东是海洋大县，214 公里岸线上同时摆着旅游、核电、海上风电、LNG、渔业与海龟保护区。这一页把它的产业主体、镇街与几条发展路径铺成十个页面，一页只做一件事。

单文件离线运行，双击即开。

## 打开方式

下载仓库后用浏览器打开 `index.html`；或本地起服务 `python3 -m http.server 8000`。不需要安装依赖，不上传数据。

## 十个页面

| 页面 | 文件 | 看什么 |
|---|---|---|
| 今日话题 | `index.html` | 公开信息里与惠东有关的近况，可分类、可刷新 |
| 各镇吃喝玩乐 | `town.html` | 14 个镇街的去处与当季海味农品，随机换一换推荐 |
| 关系网 | `network.html` | 33 个主体、46 条主边依次落位与生长；可切换看连接最多、位置最居中、离得最远 |
| 基本面 | `who.html` | GDP、三次产业、工业提速、海洋家底与参考轨道 |
| 五条路 | `choices.html` | 五条发展路径可开可关，成对比较结果 |
| 未来 | `future.html` | 固定起点的重复运行，给出三档结果与达标比例 |
| 风洞测试 | `windtunnel.html` | 四个滑块：台风强度、停业天数、核电延迟、女鞋景气，看结果怎么变 |
| 忽略了什么 | `blindspot.html` | 一片海的多种用法、海龟湾、小 GDP 大民生、女鞋与农渔品牌 |
| 一页报告 | `report.html` | 图文汇总，含数据来源与使用限制 |
| 结语 | `ending.html` | 四区县之间的位置关系，以及后续方向 |

## 数据来源

全部来自公开渠道：惠东县人民政府门户、统计公报、政府工作报告与计划执行报告、文旅与农业农村部门公开信息、南方+ / 惠州日报。页面标注来源与时间，查不到的标"暂缺"。

## 边界

不预测具体产值、招商成败或台风损失；页面上的结果是特定条件下的相对呈现，不是现实结论。不构成投资建议，不替代任何官方决策。
