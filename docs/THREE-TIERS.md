# 惠东产业风洞 · 三层产品结构

> 仿博罗三层母本（legacy 大众版 / v11 爱好者版 / V4 内部版），惠东先行落地。
> 纪律：纯新增，不覆盖旧版。所有真实数据标血统（A 官方公报 / B 官方核算 / C 校准假设）。

## 三层一览

| 层 | 受众 | 入口 | 核心能力 | 状态 |
|---|---|---|---|---|
| **大众版** | 吃瓜群众 | `legacy/2026-11-17/` | 11 页叙事 + 回音三件套（昵称 / 回音簿 / echo 页），互动闭环 | ✅ 上线 |
| **爱好者版** | 数据玩家 | `v2/` | 12 页研究版：现实底座 / 区域比较 / 历史诊断 / 机制框架 / 网络结构 / 路径研判 / 调研佐证 / 情景推演 / 风洞实验 / 台风沙盘 / 决策解释 | ✅ 上线 |
| **内部版** | 发改局决策辅助 | `internal/` | 七工作区：总览（三卡桌面）/ 任务 / 数据 / 调查 / 多模型实验室 / 情景风洞 / 研究档案（判断账本） | ✅ 上线 |

另有根路径公众门户（portal.html 等「新架构」）与 `data/huidong-data.js` 三层共用数据层，均保留不动。

## 数据底座

- **真实数据（A/B 级）**：2020–2025 GDP 与三产（五经普修订口径）、惠州七县区 2025 官方公报、太平岭核电并网、台风「红霞」事件与损失。
- **模拟数据（C 级）**：模型估计、情景区间、问卷（OSINT 驱动 N=800）、恢复曲线。
- **纪律**：微观系数不折算 GDP；2023 三产修订前口径单独标注；2032 三产 1:5:4 是结构罗盘，不是考核紧箍咒。

## 内部版核心机制（源自博罗 V4 概念收敛）

1. **判断卡三副面孔**：提醒卡（时间触发）/ 预警卡（阈值触发）/ 达标卡（结果触发）——本质是同一张卡带 `triggers` 数组，不是三类产品。
2. **判断账本**：预注册（判断 + 理由 + 预期信号 + 回看日期）→ 到期开奖 → 四态归档（方向✓机制✓ / 方向✓机制✗ / 判断失误 / 无法裁定）。「方向✓机制✗」是最值得复盘的一类。
3. **多模型实验室**：同一组事实切换竞争解释，各自路径 / 证据 / 最强反例 / 行动含义。
4. **达标口径内置**：达标卡第一行写清口径（绝对达标 / 进度达标 / 方向达标），避免罗盘变紧箍咒。
